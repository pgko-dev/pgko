# @pgko.dev/ugc

UGC beatmap format parsers and types for [pgko](https://pgko.dev/). Source and contribution instructions: [pgko-dev/pgko](https://github.com/pgko-dev/pgko).

Licensed under MIT.

This package provides the lightweight header parser. Complete beatmap parsing, layout,
Canvas rendering and playback live in [ugc-render](../ugc-render).
