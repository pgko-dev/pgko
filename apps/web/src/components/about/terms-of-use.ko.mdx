# 지침

최종 업데이트: 2026년 7월 22일

## 목적

pgko.dev는 사용자가 만든 UMIGURI 비트맵을 공유하는 커뮤니티 사이트입니다.

## 제휴·관계

이 사이트는 독립적인 팬 프로젝트입니다. UMIGURI, 그 개발자, 관련 권리자와 제휴되어 있지 않으며, 후원·스폰서·운영 관계도 없습니다.

이 사이트를 이용해도 UMIGURI나 타인의 음악, 아트워크, 비트맵, 상표에 대한 권리가 생기지 않습니다.

## 업로드

직접 만들었거나 공유 권한이 있는 콘텐츠만 업로드해 주세요.

다음 내용은 업로드하지 마세요:

- 공식 비트맵, 또는 허가 없이 다른 사람의 비트맵을 복사·수정한 것
- 악성코드, 손상된 파일, 속이거나 기만하는 파일
- 불법적이거나 모욕적·혐오적·유해한 내용
- 공유해서는 안 되는 개인정보나 기밀 정보

## 피드백

사이트의 콘텐츠가 권리를 침해하거나 이 지침을 위반하는 경우, 소개 페이지의 지원 채널로 연락해 주세요. 해당 콘텐츠 URL과 문제에 대한 간단한 설명을 함께 보내 주세요.
